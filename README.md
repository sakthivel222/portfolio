# Sakthivel R — AI & ML Engineer Portfolio

A high-impact, neo-brutalist portfolio website built for **Sakthivel R**, inspired by the award-winning aesthetic of [manx-13.vercel.app](https://manx-13.vercel.app/work).

---

## ✨ Features & Highlights

- **Neo-Brutalist Typography & Aesthetics**:
  - `League Gothic`: Bold, condensed headlines (`PORTFOLIO`, `MY WORK`, `SELECTED PROJECTS`, `WANT SOMETHING LIKE THIS?`).
  - `Londrina Solid`: Punchy buttons, tags, badges, and navigation items.
  - `Anton`: Heavy display headings and project names.
  - `Inter`: Clean, legible body typography.
  - Signature **Electric Lime** (`#adeb33`) accents, slanted badges, ambient blur orbs, and deep black (`#000000`) surfaces.
- **Dedicated Work Page (`/work`)**:
  - Matches the exact layout, animations, and interactions of `https://manx-13.vercel.app/work`.
  - Featured highlights with hover zoom, year badges, and custom accent overlays.
  - Domain highlight banner: *"5 Real-World AI & Full-Stack Apps That Deliver Impact"*.
  - Category filters: *"All", "Artificial Intelligence", "Generative AI", "Full Stack", "NLP & RAG"*.
  - Interactive project detail modal with gallery switcher, specs, features, and direct GitHub / demo links.
  - Previous / Next project navigation with keyboard arrow key support.
- **Neo-Brutalist Hero (`/`)**:
  - Giant `PORT` + Sakthivel portrait + `FOLIO` layout.
  - Slanted sticker badges: `AI & ML ENGINEER` and `GENERATIVE AI • RAG • FULL STACK`.
  - Tech stack grid, stats counters, and project highlights.
- **About Page (`/about`)**:
  - Academic background at Rajalakshmi Institute of Technology, Chennai (B.E. AIML 2024–2028).
  - Verified Industry Certifications: IBM Python for Data Science, MongoDB Associate, IBM ML for Data Science.
  - Hackathon milestones and problem-solving contests.
  - Downloadable resume action.
- **Capabilities & Services (`/services`)**:
  - Breakdown of Generative AI & RAG, Full Stack Development, ML & NLP, and Backend & Cloud APIs.
  - 4-step engineering process: Discover → Architect → Build → Evaluate & Deploy.
- **Contact Page (`/contact`)**:
  - Direct communication channels (Email, Phone, LinkedIn, GitHub, Chennai).
  - Interactive contact form with real-time feedback and validation.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

---

## 🌐 Deploy to Vercel

You can deploy this directly to Vercel with one click:
```bash
npx vercel
```
Or connect your GitHub repository to [Vercel](https://vercel.com) and set the framework preset to **Vite**.
